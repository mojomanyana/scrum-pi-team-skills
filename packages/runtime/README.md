# Governed local runtime

Private SPTS runtime package for Node 24 on Linux/WSL.

SPTS-7 `createPiLaunchPlan` is pure and issues immutable in-process authority. SPTS-8 `startGovernedLocalProcess` executes only that exact issued object with `shell:false`, an explicit environment, foreground pipe/wait supervision, and a dedicated POSIX process group. `detached:true` creates the group; `unref()` is never used. The successful spawn's validated positive child PID is retained as the PGID only inside the live handle. No caller supplies a PID or PGID, and the supervisor PID is rejected.

Direct-child close is not process-group absence. The Linux adapter probes `kill(-pgid, 0)`, treating ESRCH as absent, success as alive, and EPERM or unexpected errors as fixed fail-closed supervisor failures. Termination probes first, sends SIGTERM only to a present group, polls throughout the bounded grace, escalates a still-present group to SIGKILL, and polls through immutable `killConfirmationMs` using bounded `processGroupPollIntervalMs`. The same cleanup runs when descendants outlive a naturally closing leader. Such containment emits `descendant_cleanup_required` and `process_killed` evidence and cannot report an ordinary clean success.

Environment values are copied into private policy storage and are never exposed in policy objects or lifecycle receipts. Output is streamed and represented in receipts only by byte counts and SHA-256 digests. The injected clock, execution-ID source, group-liveness process adapter, `ReceiptSink`, and filesystem fault seam support deterministic fixture tests. Writer finalization is idempotent and exactly once after every successful open. Runtime and poll timers are cleared deterministically; terminal receipt/anchor creation, writer close, termination resolution, and public exit resolution wait for confirmed group absence. The first confirmed absence is sticky and stops all future signaling, preventing long grace or confirmation bounds from retaining the host after the group is gone.

POSIX exposes a numeric PGID rather than an unforgeable group handle. Reuse between an alive probe and a subsequent signal remains a residual kernel identity race; orphan or zombie reaping can also delay ESRCH. The supervisor minimizes that boundary with spawn-derived authority and the permanent stop after first absence, and it fails closed at the bounded confirmation deadline rather than claiming successful cleanup.

The canonical SHA-256 JSONL chain enforces lifecycle order, exit/outcome consistency, constant identities, contiguous sequence, and exact nondecreasing `YYYY-MM-DDTHH:mm:ss.sssZ` timestamps. A separate `spts.lifecycle-receipt-anchor/1.0.0` terminal contract is authenticated with HMAC-SHA256. `createReceiptAuthenticator` copies at least 32 key bytes into private authority and exposes only its immutable identifier; inspection requires the issued authenticator, chain, and anchor. Tags use timing-safe comparison, and no key is exported, persisted, logged, placed in diagnostics, or included in ordinary evidence.

The filesystem sink requires an existing absolute normalized trusted parent owned by the process uid with mode `0700`. It rejects traversal, NUL, symlinked components, unsafe modes, and collisions; creates one controlled mode-`0700` execution child; and exclusively creates mode-`0600` receipt and anchor files using `O_NOFOLLOW` where supported and descriptor identity checks. Its write-all loop retries EINTR, completes short writes, rejects zero/invalid progress, synchronizes complete lines, poisons failed writers, and closes descriptors deterministically. Inspection accepts only trusted parent plus execution ID. Replacement by the same privileged owner of an otherwise valid trusted parent is outside this process-local pathname boundary; stronger OS containment is required to exclude that owner.
